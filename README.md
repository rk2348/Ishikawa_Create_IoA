## 概要 (Overview)
プレイヤー自身が刀を振るい、迫り来る九谷焼を両断する時代劇風のVR剣戟アクションゲームです。
単なるプロトタイプではなく、製品レベルでの動作を想定し、マルチプラットフォーム（PCVR / スタンドアローンVR）での安定したフレームレート維持と、VR特有の没入感を損なわないUX設計に徹底してこだわりました。

## 展示・出展実績 (Exhibitions & Achievements)
* **「石川キッズゲームクリエイターコンテスト」出展作品**
  本タイトルは、同イベントにて一般展示を行いました。VR機器に不慣れな一般ユーザー（特に子供たち）がプレイすることを想定し、事前の説明がなくても直感的に遊べる「巻物を斬ってスタートするUI」や、激しい操作でも破綻しない「堅牢な物理演算・当たり判定」など、現場でのスムーズな体験を担保するための設計・チューニングを施しています。

## 技術スタック (Tech Stack)
- **Game Engine**: Unity (2022.3.62f1)
- **VR Framework**: OpenXR
- **SDK / Packages**: XR Interaction Toolkit, Meta XR Core SDK
- **Language**: C#

## 技術的なハイライト (Technical Highlights)
本作の開発において、ゲームとしての「手触り」と、VRにおける「快適な動作」を両立させるため、以下の技術的課題を解決しています。

### 1. 物理演算の安定化と高速衝突判定
- **貫通バグの解消**: プレイヤーが刀を高速で振った際、フレーム間に発生する当たり判定のすり抜け（ゴースト現象）を防ぐため、武器のRigidbody設定を `Continuous`（連続的衝突検出）に最適化し、正確で爽快な斬撃判定を実現しました。

### 2. 限界まで描画負荷を下げるパフォーマンスチューニング
- **手動オクルージョン・カリング**: プレイヤーの死角になる建物の裏側などのメッシュを個別に削除し、ドローコールを削減。
- **物理演算負荷の低減**: ゲームプレイに直接干渉しない背景オブジェクトから不要なColliderを完全に排除し、CPUの演算コストを最小化しました。
- **ローポリゴン化によるGPU負荷軽減**: 画面内に大量に生成される「皿」などのターゲットオブジェクトを、視覚的品質を落とさずにローポリゴンモデルへ置き換えています。

### 3. 没入感を高めるDiegetic UIの設計
- **シーン遷移のシームレス化**: タイトル画面で「システムメニューのボタンを押す」のではなく、「目の前にある巻物を斬る」ことでゲームが開始する非言語的なUI（Diegetic UI）を採用しました。
- **World Space UIの活用**: プレイ中のスコアや残り枚数を、画面に張り付く2Dテキストではなく、空間内の「看板」として配置することで、VR特有の酔いを防ぎつつ世界観を統一しています。

### 4. 拡張性を意識したアーキテクチャ設計
- **スコア管理の疎結合化**: `ScoreManager` をシングルトンパターンで実装し、スコア計算ロジックをカプセル化。シーン遷移やリトライ時に確実な初期化処理が走る堅牢なデータ管理を行っています。
- **シーンのクリーンアップ**: シーン遷移時に不要なカメラが重複して描画負荷やバグを引き起こさないよう、カメラリグのライフサイクルを厳密に管理しています。

## インストールとプレイ手順 (Installation & How to play)
1. 本リポジトリをクローンまたはダウンロードします。
2. Unity (推奨バージョン: 2022.3.62f1) でプロジェクトを開きます。
3. OpenXR対応のVRヘッドセットを接続し、Playボタンを押して開始します。
